# Dataset Instructions

The datasets used in this project are publicly available and were
originally published by Olist on Kaggle.

The raw CSV files are not included in this repository.
Please download the datasets from the original sources.

## 1. Brazilian E-Commerce Public Dataset by Olist

Source:
https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce

Download the dataset and extract the following files into this folder:

- olist_customers_dataset.csv
- olist_geolocation_dataset.csv
- olist_order_items_dataset.csv
- olist_order_payments_dataset.csv
- olist_order_reviews_dataset.csv
- olist_orders_dataset.csv
- olist_products_dataset.csv
- olist_sellers_dataset.csv
- product_category_name_translation.csv

## 2. Marketing Funnel by Olist

Source:
https://www.kaggle.com/datasets/olistbr/marketing-funnel-olist

Download the dataset and extract the following files into this folder:

- olist_closed_deals_dataset.csv
- olist_marketing_qualified_leads_dataset.csv
